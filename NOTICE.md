# Attribution and design lineage

This project uses the architecture of the official Catppuccin Zed port as a
reference: a small extension manifest, generated theme artifacts, editor tasks,
CI checks, and a single source of truth for color roles.

Catppuccin for Zed is Copyright (c) 2021-present Catppuccin Org and is
distributed under the MIT License:

- https://github.com/catppuccin/zed

Night Owl by Sarah Drasner is used as a design reference, not bundled as a
theme artifact:

- https://github.com/sdras/night-owl-vscode-theme

Sanzo Wada's color combinations are being researched as historical design
input. Any digital dataset considered for inclusion must be reviewed for its
own provenance and license before colors are copied into this repository.
