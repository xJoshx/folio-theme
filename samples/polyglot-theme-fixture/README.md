# Polyglot Theme Fixture

This is a deliberately small, non-runnable project for exercising Zed theme
highlighting. It contains representative syntax for 73 languages, frameworks,
markup formats, and configuration files. The files are numbered so they are
easy to open in sequence.

Framework-specific examples are named after the ecosystem they exercise:
React, Vue, Svelte, Astro, Angular, Next.js, Nuxt, Solid, Preact, Qwik,
Django, FastAPI, Flask, Spring, Android, SwiftUI, Flutter, Phoenix, Rails,
Laravel, and more.

Most files are intentionally short. Look for generics, decorators, pattern
matching, async code, queries, markup, interpolation, comments, and strings.
